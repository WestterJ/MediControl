☁️ Sincronização automática na nuvem

A conexão é configurada uma única vez na implantação. O indicador no topo mostra a data e o horário do último registro gravado na nuvem.

Execute o SQL de configuração no SQL Editor do Supabase. Use somente a chave pública (publishable/anon), nunca service_role. Para Google, habilite o provedor Google em Supabase → Authentication → Sign In / Providers.

🔔 Lembretes de medicamentos no celular

Ative as notificações para receber um aviso perto do horário cadastrado nas rotinas. A permissão é concedida pelo navegador e precisa ser ativada neste dispositivo.

Verificando suporte do navegador...

Os avisos aparecem enquanto o app estiver aberto ou em segundo plano. O navegador pode suspender o app e atrasar ou impedir o lembrete; para doses importantes, use também um alarme do celular.

Importante: para alertar no horário, mantenha o MediControl aberto ou minimizado. Se o navegador/app for fechado, o celular reiniciado ou o sistema suspender a página, o aviso pode não ser entregue. Notificação garantida com o app fechado exige uma versão PWA com serviço de notificações push.

Backup e segurança

O backup JSON continua disponível no menu. A sincronização usa autenticação e políticas RLS para que cada conta acesse somente seus próprios dados.
